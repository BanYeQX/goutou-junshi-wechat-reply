# 狗头军师 · 微信回复版本（Windows 版）

Windows 本地桌面工具，给**你指定的一位微信好友**托管回复、出谋划策：

- **托管**：读屏识别新消息 → 大模型生成回复 → 粘贴到输入框并逐字回读 → 按一次回车 → 核验是否发出。随时停下由你接手。
- **军师**：把对话读进来（或粘贴），给出对方可能的意图（附模型估计的把握）、依据、已知 / 未知、策略建议、什么时候该停，
  以及 3 条候选回复（各附理由和代价）；可一键“更像我一点”按你的口吻改写。**只显示和复制，不替你发。**
- **对象画像**：从你确认过的对话里，总结对方在聊天里**看得到的**特点（说话方式、兴趣话题、作息、边界、提到的事），
  每条附对方原话作依据，**你勾选后才保存**；之后军师和托管都会参考。
- **聊天节奏 K 线**：导入聊天 CSV，看消息往来方向的变化（不是好感分数）。

> 预览版。作者在 Windows 11 + 微信 PC 4.1.15.13（窗口最大化）上实机验证过；其他版本、缩放比例或布局可能需要调整。

## ⚠️ 使用前请读

- **微信不允许第三方自动化**。使用托管可能导致账号被限制或封禁，风险由你自己承担。
- 只用于你本人的正常聊天。不要用来骚扰、欺骗、施压或操控任何人；对方要求停止联系时，程序会停止并且不再给建议。
- 对方问“你是不是 AI / 是不是本人”、涉及转账借钱、验证码、自伤等情况，程序会交还给你本人处理，不会替你编造。
- 生成回复和分析时，**对话内容会发送给你配置的模型服务**（DeepSeek / OpenAI 等），会产生费用；第一次使用需要你在设置里明确同意。
- 所有资料（API Key、联系人、画像、标定、发送账本）都只保存在本机 `data/` 目录，不会上传到本仓库。

## 环境要求

- Windows 10 / 11（64 位）
- 微信 PC 版 4.x，**窗口最大化**
- [Python 3.12](https://www.python.org/downloads/)（安装时勾选 “Add python.exe to PATH”）
- 一个模型服务：DeepSeek API Key、OpenAI API Key，或 ChatGPT 账号登录

## 安装

1. 下载本仓库（右上角 **Code → Download ZIP** 后解压，或 `git clone`）。
2. 双击 **`install.cmd`**：会在项目目录里建一个 `.venv` 并安装依赖（第一次需要几分钟）。

## 第一次配置（每位好友一次）

1. 双击 **`start.cmd`** 打开“聊天台”：
   - 点 **设置与我的口吻**：选模型服务、填 API Key，勾选“允许发送上下文到该服务”；写几句你平时说话的样子（“我的口吻”）。
   - 点 **+ 添加联系人**：备注名要和微信里显示的**完全一致**。
   - 在微信里打开和这位好友的聊天，回到聊天台点 **区域校准**，按提示框选聊天标题和消息区（只在本机内存里截图）。
2. 把微信**最大化**、停在这位好友的聊天上，双击 **`calibrate-maximized.cmd`**：
   按提示手动在输入框输入一句固定测试文字（**不要发送**），再依次框选 **消息区 → 输入框 → 发送按钮**，
   最后手动删掉测试文字并确认。程序不会替你输入、点击或发送。

标定和微信窗口的位置、大小、缩放绑定；之后如果移动了微信、改了缩放或换了显示器，需要重新标定。

## 日常使用

双击 **`start-hosting.cmd`** 打开托管窗口，顶部三个标签：

- **托管**：左侧选好友 → 点“开启托管”。只处理开启之后的新消息；你在微信里自己回一句，它会判断为你接手并停下。
  托管期间**不要滚动聊天记录**（会暂缓处理，回到底部后继续）。结果不确定时会冻结、不重发，需要你在“冻结记录…”里确认。
- **军师**：点“从微信读取”（会核对聊天标题必须是左侧选中的好友），检查读到的内容后点“分析并给回复”；
  候选可右键或点按钮复制，“更像我一点”可改写。“总结画像”会弹出建议，只保存你勾选的。
- **聊天节奏**：导入 CSV（表头 `timestamp,sender,message`，sender 填 `me` 或 `other`，时间从早到晚），或看内置示例。

左侧 **+ 添加 / 编辑资料** 可以改关系阶段、聊天目标、背景，并查看 / 删除对象画像。

## 安全设计（摘要）

- 粘贴后用剪贴板逐字回读，内容不一致绝不按回车；输入框里已有你的草稿（文字或图片）就不碰。
- 回车前先写发送账本；发送结果不确定就冻结，必须人工确认，不自动重试、不因重启解冻。
- 只处理已标定的那位好友；聊天标题对不上、窗口位置变了、往上翻了聊天记录，都会暂停或暂缓。
- 军师和画像只显示、只复制，从不往微信里输入；画像只记录对方原话里能找到依据的内容，不做性格、心理或“喜不喜欢你”的判断。

## 可选：完整的“狗头军师”规则

程序默认用一套内置的精简规则。若把 [jev-chat](https://github.com/shengjidaguai-china/goutoujunshi-jev-chat)
仓库里的 `SKILL.md` 和 `references/practical/实战话术编排器：从一句回复到后续分支.md`
放到 `%USERPROFILE%\.codex\skills\goutoujunshi\`（保持同样的目录结构），程序会自动加载完整规则。
